LỆNH REMOTE SAU KHI ĐÃ ĐƯA BOOTSTRAP LÊN GITHUB

PowerShell:
irm https://raw.githubusercontent.com/<GITHUB_OWNER>/<GITHUB_REPO>/main/bootstrap.ps1 | iex

Thay <GITHUB_OWNER> và <GITHUB_REPO> bằng repo thật của bạn.
Ví dụ:
irm https://raw.githubusercontent.com/khangabc/safe-windows-cleanup/main/bootstrap.ps1 | iex

Luồng chạy:
1. Chọn ngôn ngữ: Tiếng Việt / English
2. Hiển thị TOS
3. A = Accept, D = Decline
4. Nếu chấp nhận: tải engine từ GitHub
5. Tải bloatware-list.json
6. Yêu cầu quyền Administrator
7. Mở TUI Safe Windows Cleanup
