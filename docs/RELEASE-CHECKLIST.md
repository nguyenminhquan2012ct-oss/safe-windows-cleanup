# Release Checklist / Checklist phát hành

## Tiếng Việt

- [ ] Cập nhật version trong bootstrap và engine.
- [ ] Tăng `TosVersion` nếu TOS thay đổi.
- [ ] Kiểm tra `src/Config/tos.md` có đủ Việt và English.
- [ ] Chạy parser check cho bootstrap và engine.
- [ ] Kiểm tra `-Language vi`.
- [ ] Kiểm tra `-Language en`.
- [ ] Kiểm tra Dry-Run.
- [ ] Kiểm tra UAC / Administrator.
- [ ] Kiểm tra bloatware allowlist.
- [ ] Kiểm tra release workflow.

## English

- [ ] Update bootstrap and engine versions.
- [ ] Bump `TosVersion` if the TOS changes.
- [ ] Verify `src/Config/tos.md` contains both Vietnamese and English sections.
- [ ] Run parser checks for bootstrap and engine.
- [ ] Test `-Language vi`.
- [ ] Test `-Language en`.
- [ ] Test Dry-Run.
- [ ] Test UAC / Administrator elevation.
- [ ] Test the bloatware allowlist.
- [ ] Test the release workflow.
